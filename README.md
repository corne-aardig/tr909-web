# TR-909 Web

A web tribute to the Roland TR-909 Rhythm Composer: an 11-voice drum machine with a
16-step hardware-style sequencer, 8 pattern slots, a sequenceable accent lane, and
working knobs (tune, decay, tone, snappy, attack, levels) driven by Web Audio DSP.

Live on the drumcomputer Webflow site. Since v2 the faceplate is built as native
Webflow layers (classes + a "TR-909" variable collection for colors/fonts); only the
behavior script is external, loaded from the page's footer custom code:

```html
<script src="https://cdn.jsdelivr.net/gh/corne-aardig/tr909-web@2.0.0/tr909.js" defer></script>
```

`tr909.js` hydrates the static markup via `data-t9-*` attributes — see `faceplate.html`
(generated by `gen-faceplate.cjs`) for the exact structure the script expects. The same
fragment powers the local harness (`index.html`), so local dev matches the live site.

Local dev: serve this folder over HTTP (`python3 -m http.server`) and open `index.html`.
